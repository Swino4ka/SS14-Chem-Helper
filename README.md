# ChemHelper

ChemHelper is a web application that helps calculate the required amounts of reagents for creating chemical substances in the game Space Station 14.

The application is available at: https://swino4ka.github.io/SS14-Chem-Helper/

## Features

* Calculates the required amount of reagents for a specified quantity of a chemical.
* Allows you to select the material to be crafted.
* Adds selected materials to the production list.
* Displays the final list of required reagents.

## Installation

1. Clone the repository or download the project files.
2. Start a local HTTP server from the project root, for example: `python -m http.server 8000`.
3. Open `http://localhost:8000` in your browser. The server is required to load YAML recipes and translation files.

The language can be switched using the `RU / EN` dropdown next to the theme button. Your selection is saved between visits.

## Usage

1. Enter the desired amount of the chemical (in units) in the corresponding field.
2. Select the required material from the dropdown list.
3. Click the **"Add Material"** button to include it in the calculation.
4. The final list of calculated reagents will be displayed in the **"Required Reagents"** section.

# RU
# ChemHelper
ChemHelper - это веб-приложение, которое помогает рассчитывать количество необходимых реагентов для создания химических препаратов в игре Space Station 14.
Приложение доступно по следующей ссылке: https://swino4ka.github.io/SS14-Chem-Helper/

## Функциональность
- Рассчитывает необходимое количество реагентов для заданного количества препарата.
- Позволяет выбрать материал для создания.
- Добавляет выбранные материалы в список для производства.
- Отображает итоговый список необходимых реагентов.

## Установка
1. Склонируйте репозиторий или скачайте файлы проекта.
2. Запустите локальный HTTP-сервер из корня проекта, например: `python -m http.server 8000`.
3. Откройте `http://localhost:8000` в браузере. Сервер нужен для загрузки YAML-рецептов и файлов переводов.

Язык переключается в выпадающем меню `RU / EN` рядом с кнопкой темы. Выбор сохраняется между посещениями.

## Использование
1. Введите количество препарата (в юнитах) в соответствующее поле.
2. Выберите необходимый материал из выпадающего списка.
3. Нажмите кнопку "Добавить материал", чтобы включить его в расчет.
4. В разделе "Необходимые реагенты" отобразится итоговый список с рассчитанными данными.
